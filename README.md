# Crosswind

A small browser game. Fly a plane through a storm, steer around the lightning cells, and grab fuel cans before the tank runs dry. The storm speeds up the farther you go.

## Play

Open `index.html` in any modern browser. There's nothing to install.

To play it online, turn on GitHub Pages for this repo (Settings → Pages → Deploy from branch → `main` / root).

## Controls

| Action | Keyboard | Phone / tablet |
|---|---|---|
| Climb / descend | `↑` `↓` or `W` `S` | Drag up and down |
| Pause | `P` | — |
| Start / restart | `Enter` | Tap the button |

Your best distance is saved in your browser.
